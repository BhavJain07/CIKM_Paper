\section{Official paper template}

CIKM requires the \textbf{ACM Master Article Submission Template} (2-column), not a custom CIKM \texttt{.tex} file.

\begin{itemize}
\item Download: \url{https://www.acm.org/publications/proceedings-template}
\item LaTeX class: \texttt{acmart}, proceedings option: \texttt{sigconf}
\item Repository manuscript: \texttt{paper/main\_acmart.tex}
\end{itemize}

\noindent Review-oriented preamble:
\begin{verbatim}
\documentclass[sigconf,anonymous,review]{acmart}
\setcopyright{none}
\settopmatter{printacmref=false}
\end{verbatim}

\textbf{Page limit:} at most 10 pages including figures, tables, and appendix content, plus up to 2 additional pages used only for references. Overlength papers are desk-rejected.

\section{Full paper upload (May 23)}

\textbf{Avoid desk rejection}
\begin{itemize}
\item Upload \texttt{main\_acmart.pdf} in ACM 2-column format.
\item Double-blind PDF: no names, affiliations, acknowledgments, or identifying URLs.
\item Third-person self-citations only.
\item Respect page limits.
\item Authorship unchanged since abstract registration.
\item Reviewer nomination completed at abstract stage.
\item Work not concurrently under review elsewhere.
\end{itemize}

\textbf{Build PDF}

\textit{Overleaf (recommended):} Upload \texttt{paper/overleaf\_bundle/} (create with \texttt{bash scripts/package\_overleaf.sh}). Set main file \texttt{main\_acmart.tex}. Compile with pdfLaTeX + BibTeX.

\textit{Local:} Full MacTeX/TeX Live with \texttt{acmart} dependencies:
\begin{verbatim}
cd paper
pdflatex main_acmart.tex && bibtex main_acmart
pdflatex main_acmart.tex && pdflatex main_acmart.tex
\end{verbatim}

\textbf{Reproducibility} (optional anonymous GitHub link in paper):
\begin{verbatim}
bash scripts/reproduce_full.sh
python -m provbench_rag.scripts.export_paper_artifacts
\end{verbatim}
